Its Your Friendly Neighborhood Navigator with an exciting announcement: Nav2’s Lyrical Release!

[![Image 1: image](https://us1.discourse-cdn.com/flex022/uploads/ros/optimized/3X/9/5/95cfb4ebaafee207c4b76b18ccb03c571df4056a_2_500x500.jpeg)](https://us1.discourse-cdn.com/flex022/uploads/ros/original/3X/9/5/95cfb4ebaafee207c4b76b18ccb03c571df4056a.jpeg "image")

(I just couldn’t help myself; this is just too cool. If anyone has swag ideas for this, let me know!)

This release marks some of the most exciting and broad updates made in several distributions, including:

*   New `nav2_ros_common` package which makes major headway into abstracting ROS APIs into a common location for easier software development and compliant node development, which will continue to be developed over time
*   New to MPPI: open-loop control mode, dynamics support, asymmetric acceleration limits, plugin motion models, trajectory validators, delay compensation, and more!
*   New Pause and Resume capabilities powered by the `PauseResumeController` BT node from [@redvinaa](https://discourse.ros.org/u/redvinaa)
*   New Vector Object Server to work with polygon and shape data with costmap 2D, costmap filters, and other key integrations by [@Sushant-Chavan](https://discourse.ros.org/u/sushant-chavan) and continued work from my time at Samsung Research
*   New Adaptive Goal Checker with coarse and fine criteria for more accurate goal achievement [@DavidG-Develop](https://discourse.ros.org/u/davidg-develop)
*   A litany of new features for RPP including the support for Dynamic Window Pure Pursuit to consider dynamic limitations during path tracking [@Decwest![Image 2: japan](https://emoji.discourse-cdn.com/noto/japan.png?v=15)](https://discourse.ros.org/u/decwest)
*   New support for IPC within composed bringups for true zero-copy communications
*   The start of support by measuring path tracking bounds in the controller server which may be used by the behavior tree, costmap plugins, controllers, and other algorithms to improve behaviors @silanus23[@mini-1235](https://discourse.ros.org/u/mini-1235)
*   Massive speed ups in the Inflation Layer aided by a new algorithm, optional OpenMP processing, as well as an symmetric inflation layer to incentivize left- or right-hand side passing [@tnajjar](https://discourse.ros.org/u/tnajjar)[@mbloechli](https://discourse.ros.org/u/mbloechli)
*   Collision monitor toggles, exclusion zones, and costmap sources

… and literally _so, so much more_

One thing I’m particularly proud of with the dedication, time, and support of @AJedancov is a **[brand new, fully redesigned Nav2 documentation website](https://docs.nav2.org/)** which is now live!

[![Image 3: image](https://us1.discourse-cdn.com/flex022/uploads/ros/optimized/3X/4/0/4048ccee73d9357d2e365309ffb2bb15fe201ce8_2_690x385.jpeg)](https://us1.discourse-cdn.com/flex022/uploads/ros/original/3X/4/0/4048ccee73d9357d2e365309ffb2bb15fe201ce8.jpeg "image")

Not only is it more beautiful, we now have support for separate documentation versions per-distribution to support distribution life-long documentation, tutorials, and guides for each currently active ROS distribution, and dark mode. Alot of time and effort went into this work and I hope you enjoy this new experience!

This has been a truly exciting past year and its been a pleasure to try to keep up with all the amazing ways people are using Nav2 and ROS in their applications and building in the open to improve the industry together. If you’re using Nav2, I highly encourage you get involved!

All of this is only possible due to the support of our sponsors, so I’d like to make sure we thank Dexory, Polymath Robotics, **NVIDIA, AMD, StereoLabs, 3Laws, and Staer** for their excellent partnership, support, and collaboration.
