## [](https://discourse.ros.org/t/x/57685#p-117299-new-agenda-items-2)New agenda items

*   **Avoid GitHub PR Stacks**: The PMC recommends avoiding GitHub PR stacks (`gh-stack`) for now for all Gazebo committers due to an upstream bug ([gh-stack#371](https://github.com/github/gh-stack/issues/371)) that produces malformed commit author attributions.
*   **Deprecating FreeImage for Ubuntu 26.04 (Resolute) / Jetty**: Because FreeImage is being deprecated across package managers ([homebrew-simulation#3298](https://github.com/osrf/homebrew-simulation/issues/3298)), the team agreed to drop FreeImage from 26.04 Jetty debs ([ogre-2.3-release#11](https://github.com/gazebo-forks/ogre-2.3-release/pull/11)), deploying first to nightly / Rotary builds.
*   **Gazebo-M Naming Process**: Screened candidate names on the [namestorming sheet](https://docs.google.com/spreadsheets/d/1dveyz4Oc3akVfmwRcgmYxy9KUuy7b5aRJx6kUgb9gq0/edit?usp=sharing), filtering out candidates with trademark or spelling issues. Be on the look out for a public poll to choose the name of the next Gazebo release.
*   **Pixi Environment Updates**: Updating Pixi environment configurations to match Ubuntu Resolute for Gazebo Rotary ([ros2#1834](https://github.com/ros2/ros2/pull/1834)).
*   **Bazel Maintenance Hand-off**: Coordinating maintenance duties and Central Registry (BCR) access for Bazel build rules across repositories.

## [](https://discourse.ros.org/t/x/57685#p-117299-updates-3)Updates

### [](https://discourse.ros.org/t/x/57685#p-117299-buildfarm-infrastructure-4)Buildfarm & Infrastructure

*   **Buildfarm Status**: No new buildfarm issues this week. Tracking open issues on the [Dashboard](https://osrf.github.io/buildfarm-tools/dashboard/index.html) including `UNIT_Server` timeout ([gz-sim#3829](https://github.com/gazebosim/gz-sim/issues/3829)) and `ApplyLinkWrenchTestFixture` flakiness ([gz-sim#2727](https://github.com/gazebosim/gz-sim/issues/2727)). Investigating a failed `BuoyancyTest.UniformWorldMovement` build on Rotary Resolute.

### [](https://discourse.ros.org/t/x/57685#p-117299-testing-continuous-integration-5)Testing & Continuous Integration

*   **Bazel Test Flakiness CI**: Added Bazel CI workflows ([gz-math#820](https://github.com/gazebosim/gz-math/pull/820), [gz-transport#939](https://github.com/gazebosim/gz-transport/pull/939)) to repeatedly run test suites and isolate flaky targets.
*   **gz-transport Test & CLI Improvements**: 
    *   Replaced deterministic sleep calls with `waitUntil` condition checks in `Node_TEST` and `gz_TEST` across supported release branches ([Rotary](https://github.com/gazebosim/gz-transport/pull/941), [Jetty](https://github.com/gazebosim/gz-transport/pull/944), [Ionic](https://github.com/gazebosim/gz-transport/pull/945), [Harmonic](https://github.com/gazebosim/gz-transport/pull/946)).
    *   Improved `gz topic publish` CLI command handling across branches ([Rotary](https://github.com/gazebosim/gz-transport/pull/930), [Jetty](https://github.com/gazebosim/gz-transport/pull/933), [Ionic](https://github.com/gazebosim/gz-transport/pull/934), [Harmonic](https://github.com/gazebosim/gz-transport/pull/935), [Fortress](https://github.com/gazebosim/gz-transport/pull/936)) and fixed `gz_TEST.TopicPublish` ([Rotary](https://github.com/gazebosim/gz-transport/pull/929), [Fortress](https://github.com/gazebosim/gz-transport/pull/932)).

### [](https://discourse.ros.org/t/x/57685#p-117299-physics-simulation-6)Physics & Simulation

*   **Dynamic Mesh Volume Calculation**: Updated `gz-sim` to compute duck volume expectations directly from mesh geometry instead of a hardcoded constant ([gz-sim#3912](https://github.com/gazebosim/gz-sim/pull/3912)).
*   **Centroid-Based Buoyancy**: Updated `gz-sim` to apply buoyancy forces at the collision geometry centroid while properly respecting mesh scaling ([gz-sim#3909](https://github.com/gazebosim/gz-sim/pull/3909)).
