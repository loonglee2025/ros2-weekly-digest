Hello community,

I have been working on extending the DENSO robot ROS 2 stack to support new research and operation scenarios with these robots using ROS. Originally, the stack supported ROS Humble, MoveIt2, and Gazebo Classic for the VS-060, Cobotta, and HSR-065 robots. The modifications include:  
 • Added support for the VS-050  
 • Updated to Gazebo Fortress (Humble)  
 • Added MoveIt Servo  
 • Added support for operating two VS-050 robots simultaneously  
 • Added a ROS Jazzy version of the stack with all the previous modifications

You can check the GitHub repository below:

[github.com](https://github.com/lpstrevisan/denso_robot_ros2)

![Image 8](https://us1.discourse-cdn.com/flex022/uploads/ros/optimized/3X/1/5/15437d8106b9f385b58e4c13062d462c9dfb3b44_2_690x344.png)
### [GitHub - lpstrevisan/denso_robot_ros2](https://github.com/lpstrevisan/denso_robot_ros2)

Contribute to lpstrevisan/denso_robot_ros2 development by creating an account on GitHub.

Feel free to check out the repository. Suggestions and improvements are more than welcome!

Unfortunately, I removed the HSR-065 because I could not find meshes that did not cause collisions and prevent Gazebo from starting.
